# Nutrition5k Project

A computer vision and machine learning project exploring nutritional estimation from food images using the Nutrition5k dataset.

## Files

- `Nutrition5k_Project.ipynb`: research notebook with code, analysis, visualizations, and saved outputs.
- `Nutrition5k_Project.html`: exported notebook report; download and open it in a browser.

## Project scope

The notebook covers dataset preparation, data quality checks and cleaning, exploratory analysis, unsupervised learning, and experiments with visual models including SigLIP and DINOv3. It also discusses results, limitations, and future work.

## Running

Open the notebook in Jupyter or Google Colab. Review its setup and imports, install the required packages, and follow the dataset download instructions in the notebook. Training requires suitable compute and storage. The dataset is downloaded separately and is not included in this repository.

The saved notebook and report include large embedded outputs, so downloading them may be easier than using GitHub preview.

## Dataset and references

- [My Nutrition5k dataset on Kaggle](https://www.kaggle.com/datasets/gillesokhin/nutrition5k-dataset): dataset used by this notebook, which downloads version 6 through KaggleHub.
- [Original Google Research Nutrition5k repository](https://github.com/google-research-datasets/Nutrition5k): original dataset, documentation, and evaluation scripts.
- [Nutrition5k: Towards Automatic Nutritional Understanding of Generic Food](https://arxiv.org/abs/2103.03375): the original research paper (CVPR 2021).
